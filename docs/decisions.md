プロジェクトの方針として決めたことを記録する。AIを含む作業者は、作業の前にこのファイルを読む。
方針を変える場合は、既存の項目を書き換えずに新しい項目を追加し、古い項目に「→ D-xxx で変更」と書く。

状態: **決定** ＝ オーナーが了承済み / **提案** ＝ 未了承（実装前にオーナーに確認する）

## D-001 公開版を12月の最終発表までに公開する（決定・2026-10-07）

中間発表は終了した。公開版を、12月19日の最終発表までに一般公開する。
中間発表時点のデモは、コミット `83c9cda` で参照できる。

## D-002 ターゲットと価値の中心（決定・2026-10-07）

価値の中心は「推しの刀が、いま・どこで・いつまで見られるか」を**正確に**伝えること。
機能の多さではなく、情報の信頼性と、検索やシェアからの訪れやすさで勝負する。

## D-003 刀の写真は持たない（決定・2026-10-07）

刀の写真は掲載しない。理由は次のとおり。
- 画質と体裁の統一された画像を、無料で揃えることが難しい。
- 画像の収集が、運用の負担として最も大きい。
- 刀のファンは、号・銘・来歴で刀を識別できる。

写真の代わりに、文字中心の統一デザインを採用し、公式の画像ページへの外部リンク（`official_image_url`）を置く。
シェア用の画像は、刀名を文字で組んで自動生成する。

## D-004 1件＝実物1振り。号・銘・刀匠を分けて持つ（決定・2026-10-07）

- 号で検索すると、その1振りに直接たどり着く。
- 刀匠名で検索すると、刀匠ページと、その刀匠の作の一覧が出る。
- 号のない刀も、銘や刀匠名から見つけられる。
- 展覧会の出品リストから、刀匠ページに移動できる。

詳細は data-model.md。

## D-005 会場は館の一覧（マスター）で管理し、地図は緯度経度で描く（決定・2026-10-07）

浮世絵風の地図画像と、目視でのピン位置合わせは廃止する。
地図は、国土地理院の地図（淡色地図）を Leaflet で表示し、館の緯度経度でピンを置く。表示には国土地理院の出典表記を付ける。

## D-006 展示情報は主要館に絞り、自動収集とPRでの確認で更新する（決定・2026-10-07）

- 対象館を限定し、週1回（または月1回）、各館の展覧会ページを自動で巡回する。
- AIで情報を抽出し、根拠の引用を機械的に照合したうえで、差分をPRにまとめる。
- オーナーがPRを確認して承認すると、公開される。

対象館は、刀剣情報サイトを複数調べたうえでAIが選定し、docs/venue-selection.md にまとめた15館とする（2026-10-07 オーナー了承）。15館のドメインは、クラウド環境のネットワーク設定で許可済み。

## D-007 チラシは画像ではなくリンクで扱う（決定・2026-10-07）

チラシの画像は、自前で持つことも、外部の画像を直接埋め込んで表示することもしない。
展覧会ページのURL（必須）と、チラシや出品目録へのリンクを持つ。
館から掲載許可を得られた場合に限り、例外として画像を表示する（別途の決定項目で扱う）。

## D-008 ソーシャル機能を削除する（決定・2026-10-07）

コメント欄、「行きたい」の人数表示（仮の初期値を含む）、公開範囲の設定は削除する。
フォロー機能は、ログインを伴う形では実装しない。刀ごとのカレンダー購読（.ics）で代替する。
訪剣帖は、端末内の保存に限定して残す。

## D-009 他社の作品名（刀剣ゲームなど）は前面に出さない（決定・2026-10-07）

刀剣データに「登場作品」の項目は持たない。
サービスの説明文やシェア用画像にも、他社の作品名やキャラクターの画像を使わない。
号・刀匠などの史実の名前は、通常どおり扱う。

## D-010 技術構成を Astro に移行する（決定・2026-10-07）

刀・刀匠・展覧会・館ごとに、ビルド時に静的なHTMLを生成する。これにより、検索結果への表示と、シェア時のプレビュー表示（OGP）に対応する。
動きの必要な部分（検索、地図、訪剣帖）は、既存の React の部品を流用する。
公開先は Cloudflare Pages を第一候補とする（未確定）。

## D-011 AIによる自律的な開発体制（決定・2026-10-07）

- 司令役のセッションが作業を分割し、作業役のセッションに指示する。
- 作業の単位は「2〜3時間程度で終わる、完了条件が明確な作業 → 1つのPR」とする。
- 品質の判定は、AI同士の合意ではなく、ビルド・データ検証・表示確認といった機械的なチェックで行う。
- 権利、デザインの好み、データの正しさの最終確認は、オーナーが判断する。AIは独断で決めない。

## D-012 データの扱い4点（決定・2026-10-07）

docs/migration-notes.md §8 の論点のうち、次の4点を推奨案のとおり決定した。
1. 日本美術刀剣保存協会の認定（特別重要刀剣・重要刀剣など）は、国の指定（`designation`）とは別の項目で持ち、表示する。
2. 個人を特定できない場合は、刀匠データに「流派」として登録することを認める。刀匠と流派は区別できる形にする。
3. 会期の終了日が分からない展示は、終了日を空欄にでき、「会期未定（公式サイトで確認）」と表示する。`9999-12-31` のような代用の値は使わない。
4. 他社作品とのコラボ企画（旧データの ev_36 のスタンプラリーなど）は掲載しない。刀剣の展示情報に限る。

## D-013 別名の完全一致でも刀を強調表示する（決定・2026-10-07）

号に加えて、別名（`aliases`、例：「髭切」）が完全一致し、該当する刀が1振りだけの場合も、その刀を検索結果の最上位に強調表示する。

## D-014 地図の帰属表示から国旗の図柄を外す（決定・2026-10-07）

Leaflet の名前とリンクは残し、既定で付く国旗の図柄だけを外す。国土地理院の出典表記はそのまま表示する。

## D-015 デザインは複数案を比較して選ぶ（決定・2026-10-07）

画面のデザイン（T-201）は、方向性の異なる案を2〜3案作り、オーナーが見比べて選ぶ。選ばれた案を基に、各ページの画面を作る。

## D-016 デザインは案Aを基本とし、展示情報と目録は案Bの形式にする（決定・2026-10-07）

全体の色味・装飾・書体は案A（鞘書・白鞘）とする。刀剣ごとの展示情報（状態・会場・展覧会・観覧料など）と目録（一覧）は、見やすさを優先して案B（展示目録・図録）の形式・文字の大きさ・区切り方を使い、色と書体は案Aに合わせる。詳細は docs/design/system.md。

## D-017 運用はローカルの Claude Code と GitHub Actions を中心にする（決定・2026-10-07）

- クラウドのセッションクレジット（プロモーション枠）は、期限（2026-11-05 の見込み）までに、並列の効果が大きい作業（画面の実装、15館への拡大）に使う。
- 以降の開発は、ローカルの Claude Code（デスクトップアプリ）を司令役とし、サブエージェントで作業を分担する。実装は Sonnet、設計とレビューは Opus を基本とする。
- 定期的な作業（自動チェック、週1回の巡回、公開）は GitHub Actions と Cloudflare Pages で行う。
- Antigravity は、仕様が明確な作業の予備の担当とする。Cowork は開発には使わない。

## D-018 巡回で検出した変化のデータへの反映方法（決定・2026-10-07）

1. まず、オーナーが週1回、巡回の PR を Claude Code に渡して処理を依頼する方式（C）で始める。
2. 数週間運用して1回あたりの消費量が分かったら、PR の作成をきっかけに Claude Code を GitHub Actions 上で自動実行する方式（A）に移る。Pro の契約で使えるかは、設定時に確認する。
3. A が使えない、または利用枠が厳しい場合は、Gemini API の無料枠を使う方式（B）を予備とする。どの方式でも、引用の照合（crawl:verify）を必ず通す。

## D-019 成果を main に取り込む（決定・2026-10-07）

作業用ブランチの成果がそろった時点で、main に取り込む PR を作成する。自動の巡回 PR と Cloudflare Pages の公開は main を基準にする。

## D-020 「あと○日」を表示する（決定・2026-10-07、オーナーから委任）

会期の終了日が30日以内に迫った展示に「あと○日」を表示する。日数は「終了日 − 今日（日本時間）」とし、0日は「本日まで」、1日は「明日まで」と表示する。終了日が未定の展示には表示しない。刀ごとの展示期間がある場合は、その刀の展示期間の終了日で数える。シェア用画像には入れない（D-016 の方針どおり、古くなる情報を画像に入れない）。

## D-021 名古屋刀剣博物館は自動巡回の対象から外す（決定・2026-10-07、オーナーから委任）

巡回用のアクセスが拒否される（HTTP 429）ため、回避はせず、自動巡回の対象から外す。ローカルの環境に移った後、通常の閲覧で公式ページを確認できれば、引用付きで手作業で登録する。
