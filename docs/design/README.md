# デザイン案の比較（T-201 / D-015）

オーナーが見比べて1案を選ぶための、静的なデザイン見本です。実装（Astro のページ）はまだ変えていません。
選ばれた案を基に、各ページの画面を作ります（D-015）。

### 見本に使ったデータ

`data/*.json` の実データから、次のものを使いました。値はデータの記載どおりです。

- 刀剣：三日月宗近（詳細画面・シェア画像）、厚藤四郎、後藤藤四郎、池田正宗（「いま会える刀」。池田正宗は帰属が「極め」の例）
- 展覧会：鈴木嘉定コレクション寄贈品展（刀剣博物館）、名刀のいろは（佐野美術館）、総合文化展 本館13室 刀剣（東京国立博物館）、西海道と南海道（熱田神宮）
- 表示日は **2026-10-07（日本時間）** と想定した静的な見本です。実装では、実際の今日の日付で判定します（data-model.md §9）。
- これらの展覧会は、データ上 `confidence: "unverified"` のため、見本でも「要確認」を付けています。
- 刀剣詳細の「展示状態の表示（4種類）」は、表示の型を見せるための見本で、三日月宗近の情報ではありません（画面にもそう書いています）。

### 長所と短所

**案A 鞘書・白鞘**
- 長所：刀の写真がなくても「刀らしさ」を感じられる。縦書きの号は、他のサービスとの違いがはっきりする。
- 短所：縦書きは、スマホの狭い幅でレイアウトが難しい。一覧の札は、会場や日付の欄が細くなり読みにくい（375px で会場名が4〜5文字ごとに折り返す）。筆文字は、旧字体や珍しい字で書体の差が目立ちやすい。

**案B 展示目録・図録**
- 長所：「いま・どこで・いつまで」を表の同じ位置に並べるので、正確さを伝える D-002 の方針に最も合う。UD書体で、小さい文字も読みやすい。横組みのみなので、実装とシェア画像の自動生成が容易。
- 短所：まじめで地味に見え、SNSでの拡散力は3案の中で最も弱い。表を多用するため、スマホでは表をカードに組み替える実装が必要（見本では対応済み）。

**案C 現代的で親しみやすい**
- 長所：「あと18日」のような数字が大きく、行動につながりやすい。シェア画像が目立つ。ボタンが大きく押しやすい。
- 短所：和の雰囲気が弱く、一般的なイベント情報サイトに見えやすい。差し色（黄・珊瑚）が多く、画面が増えると色の役割の管理が必要。

### 書体と読みやすさ

- 明朝体は、細い横線がスマホで薄く見えやすい。本文に明朝体を使う案A は、本文 15〜16px 以上、日付やボタンなど小さな情報はゴシック体にしています。案B・C は本文をゴシック体にしています。
- 案A の筆文字（Yuji Syuku）は号の見出しだけに使うこと。旧字体（國、廣など）や珍しい字が書体にない場合、別の書体に置き換わって見た目がそろわない。実データの号と銘の全文字で、書体に字形があるかを確認すること（要確認）。
- 日本語の Google Fonts は文字の範囲ごとに分割して配信されるため、ページで使う文字の分だけ読み込まれる。書体の数は、1案あたり3つまでに抑えています。
- 縦書き（案A）は、数字や英字の向き、長い号の折り返し、文字数による高さの違いの扱いを、実装時に個別に決める必要がある。

### シェア用画像の自動生成

- 見本は HTML で描いています。実装では、ビルド時に1200×630の画像を生成します（D-003、data-model.md §11）。
- 案A は縦書きを使います。画像生成によく使われる Satori（@vercel/og）は `writing-mode`（縦書き）に対応していないと理解しています（要確認）。案A を選ぶ場合は、1文字ずつ縦に並べるか、ヘッドレスブラウザで撮影する方式を検討する必要がある。案B・C は横組みのみで、この問題はない。
- 号の文字数で大きさを変える処理が必要（見本は5文字の「三日月宗近」で調整。6文字以上の号では文字を小さくする）。

## 要確認（オーナーの判断が必要な点）

1. **3案のうち、どれを基にするか。** 複数の案の要素を組み合わせる（例：案B の構成に、案C の「あと○日」を加える）ことも可能です。
2. **「あと○日」の数え方。** 見本では、今日（10/7）から終了日（10/25）までの差を「あと18日」としています。終了日を含めて数えるか、「最終日」の表示をどうするかを決める必要があります。
3. **シェア用画像に会期を入れるか。** 静的サイトのため、画像はビルドした時点の内容になります。SNS 側も画像を一定期間キャッシュするため、「10月25日まで」などの表示が古くなるおそれがあります。会期を入れない（刀名・銘・刀匠・所蔵だけにする）案も考えられます。
4. **案C を選ぶ場合の言葉づかい。** 「たどってきた持ち主」（伝来）、「名前の由来」（号の由来）など、くだけた見出しにしています。正式な用語に戻すかどうか。
5. **見本で使った東京国立博物館の展示情報**（三日月宗近・厚藤四郎、本館13室 〜10/25）は、データ上「未確認」です。見本では、データどおり「要確認」を表示しています。
