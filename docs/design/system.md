# デザイン仕様（D-016）

決定日: 2026-10-07
基にした見本: [proposal-a.html](./proposal-a.html)（全体）、[proposal-b.html](./proposal-b.html)（展示情報と目録）

**全体の色・書体・装飾は案A（鞘書・白鞘）、刀剣ごとの展示情報と目録（一覧）の形式は案B（展示目録・図録）** を採用する。
B の部品は、A の色と書体に置き換えて使う。B の色（紺・白地）はそのまま持ち込まない。

---

## 1. 色（案A）

| 変数 | 値 | 用途 |
|---|---|---|
| `--shiraki` | #F3EDE1 | ページの地（白木） |
| `--shiraki-2` | #EAE2D2 | 帯、区切り、表の見出し列の地 |
| `--washi` | #FBF8F2 | カード・表の地（和紙） |
| `--sumi` | #1E1B18 | 本文、太罫 |
| `--usuzumi` | #5C554D | 補足の文字、表の項目名 |
| `--kokuen` | #3A342E | 主ボタン |
| `--shu` | #A23B2A | 要確認、会期終了間近、国宝の印 |
| `--mokume` | #CFC2AB | 細罫（装飾専用。文字や入力欄の枠には使わない。コントラスト 1.51） |
| `--ok` | #2F5A3C | いま会えます |

- 文字と地の組み合わせは、すべて WCAG AA（4.5:1 以上）を満たす（README.md の表を参照）。
- 状態は色だけで示さず、必ず文字でも示す。

## 2. 書体（案A）

| 役割 | 書体 | 使う場所 |
|---|---|---|
| 筆 | Yuji Syuku | 号の見出しだけ（刀剣詳細の白鞘、シェア用画像、トップの札） |
| 明朝 | Shippori Mincho | 見出し、号・刀名、本文 |
| ゴシック | Zen Kaku Gothic New | 日付、数字、表の項目名、ボタン、注記などの小さな情報 |

- 数字が縦にそろう場所（日付、会期、料金、刃長）は `font-variant-numeric: tabular-nums`。
- 筆の書体に字形がない字（旧字体など）があると、別の書体で表示されて見た目がそろわない。実データの号の全文字で字形の有無を確認し、ない場合は明朝で表示する（T-201 で確認）。

## 3. 案Aから使うもの

- ヘッダー、ロゴ、導入部（縦書きの見出しと検索窓）
- 刀剣詳細の白鞘（号を縦書きの筆文字で見せる部分）。白鞘の継ぎ目・目釘穴を思わせる線と円の装飾
- 見出しの形（明朝＋下の太罫）、二重罫（`3px double`）
- 「要確認」の朱の枠、帰属の区別の小さな枠（在銘は実線、極めは破線）
- 出典と最終確認日の欄
- シェア用画像の構成（縦書きの号）。会期は入れるかを別途決める

## 4. 案Bから使うもの（形式・文字の大きさ・区切り方）

### 4.1 刀剣ごとの展示情報（刀剣詳細の「展示」欄）

案B の `.exhibit` の表形式にする。項目名の列と値の列に分け、行ごとに細罫で区切る。

| 行 | 内容 | 案Bの大きさ |
|---|---|---|
| 状態 | 状態の札（いま会えます等）＋終了日 | 札 15px 太字、終了日 16px 太字 |
| 会場 | 館名（館ページへのリンク）＋展示室 | 本文 14px |
| 展覧会 | 展覧会名（リンク）＋会期 | 本文 14px |
| この刀の展示 | 展示期間の区分（前期・後期、または全期間） | 本文 14px |
| 観覧料 | 料金 | 本文 14px |

- 項目名の列：幅 7.5em、12px、`--usuzumi`、地は `--shiraki-2`（案Bの `--base` の置き換え）
- 行の余白：上下 10px・左右 8px、区切りは `--mokume` の細罫
- 状態の札：地 `--ok`、文字 `--washi`（案Bの緑の札を A の松葉色に置き換え）
- 表の下に「要確認」の注意欄（案Bの `.warn`：左に 3px の朱の線、薄い地、13px）

### 4.2 目録（一覧）

トップの「いま会える刀」、刀匠ページの作品一覧、展覧会ページの出品リストは、案B の `.cat` の目録形式にする。

- 列：No.／指定／名称（号を大きく、その下に種別と銘）／刀匠〔帰属〕／会場／展示
- 大きさ：名称 21px（明朝・太字）、種別と銘 13px、No. 13px、列見出し 11px
- 行の余白：上下 14px・左右 10px、細罫で区切る。列見出しの下は `--sumi` の罫
- 帰属は〔在銘〕〔極め〕〔伝〕の亀甲括弧で、11px の補足として刀匠名の後ろに付ける
- **スマホ（767px 以下）では、表を2段組のカードに組み替える**（案Bの見本と同じ。No. を左に置き、「刀匠」「会場」「展示」の項目名を行頭に付ける）
- 会期終了が近い展覧会の一覧は、案B の `.ex-list`（左に日付を大きく、右に展覧会名と会場）。日付 24px、5日以内は朱

### 4.3 作品データ（刀剣の基本情報）

案B の `.spec` の表形式（項目名 12px の列＋値）。刃長・反りは明朝 16px で数字をそろえる。
